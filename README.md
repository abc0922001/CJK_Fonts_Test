# 漢字五方（CJK_Fonts_Test）

滑手機、看網頁或追劇看字幕時，你是否曾覺得某些繁體字「好像哪裡怪怪的」？明明看得出是同一個字，筆畫卻跟從小在學校學的不太一樣。「**漢字五方：CJK 跨地域字形一覽與即時測試**」是一個免安裝的純靜態網頁工具，不指定任何特定字型名稱，純粹透過網頁原生的語言標記，讓你直接用自己的電腦或手機，並排比較**台灣、中國、日本、韓國、香港**五地在同一套螢幕環境下的真實字形差異。

## 為什麼同一個字，在不同螢幕上會「長得不一樣」？

許多台灣讀者在瀏覽跨國網站、應用程式或字幕時，常會看到「草」字頭連成一橫、「器」字中間少了一點，或是「骨」、「沒」的寫法感覺格外陌生。這背後其實有兩個關鍵原因：

- **統一碼（Unicode）的「同碼異形」**：Unicode 是電腦用來記錄全世界文字的統一編碼標準。為了避免字元編碼重複膨脹，東亞各地寫法相近的漢字往往共用同一個碼位（例如「骨」在五地都是 `U+9AA8`），實際字形外觀則交由各地字體各自詮釋。
- **HTML `lang` 語言標記**：當編碼完全相同時，瀏覽器會依據網頁的 `lang` 屬性（`zh-TW`、`zh-CN`、`ja`、`ko`、`zh-HK`）自動挑選對應地區的系統字型。只要網頁少了正確的語言標記，台灣讀者就容易看到外地的預設寫法。

本專案刻意不指定任何外部或特定字型名稱，只切換 `lang` 屬性與通用字族（無襯線黑體／有襯線明、宋體），忠實呈現**你手上這台裝置與瀏覽器**對五地漢字標準的原生渲染結果。

## 五地字形差在哪？精選 5 個最有感的例子

以下精選 5 個台灣讀者日常生活中最容易一眼察覺差異的常用字：

| 代表字 | Unicode | 五地筆形重點差異 |
| :---: | :---: | :--- |
| 骨 | `U+9AA8` | 台灣、香港、韓國上方內部向右折，中國、日本向左折；下方「月」首筆亦有豎（台／中／日）與撇（韓／港）之分。 |
| 沒 | `U+6C92` | 台灣右上為「勹」包內撇；中國、日本、韓國、香港多作「几」。 |
| 直 | `U+76F4` | 台灣與中國下方長橫直接與「目」相連；日本、韓國、香港左側多了一道 L 形豎折托底。 |
| 草 | `U+8349` | 台灣、香港、韓國保留四畫斷開（十＋十）；中國、日本連成三畫一體。 |
| 器 | `U+5668` | 台灣、香港、韓國中央為「犬」（有右點）；中國、日本作「大」（無點）。 |

頁內共收錄 **20 個代表字圖鑑**（`骨、角、空、亮、以、沒、化、房、眾、遲、聽、經、麵、直、刃、草、雪、器、真、道`），皆附有 Unicode 碼位與五地筆形重點說明，點選字卡內文字即可直接選取複製。

## 核心功能

- **自訂文字即時比對**：輸入框預設填入 `遲眾聽經亮以角沒化骨麵房空`，可隨時輸入任意單字或句子，並透過 `28px`–`110px` 字級滑桿放大觀察筆畫細節。
- **黑體與明／宋體一鍵切換**：隨時在無襯線黑體（`sans-serif`）與有襯線明／宋體（`serif`）之間切換，比較螢幕閱讀字體與印刷風格字體的差異。
- **單檔免安裝、離線可用**：全站僅由一份獨立的 [index.html](index.html) 構成，無任何外部套件或網路字型相依，並支援行動裝置響應式排版與鍵盤無障礙操作。

## 誰適合使用？

- **一般讀者與漢字愛好者**：一次看懂台、港、日、韓、中日常漢字的細微差異。
- **網頁開發者與介面設計師**：親眼比較正確標註 `lang="zh-TW"` 與其他語言標籤的差別，並確認跨作業系統、跨瀏覽器的實際顯示效果。
- **語文教學與排印設計工作者**：快速放大對照標準字形與跨地域異體差異，作為教學或選字參考。

## 快速開始與觀察小提醒

1. 取得專案原始碼（或直接下載 [index.html](index.html)）：

   ```bash
   git clone https://github.com/abc0922001/CJK_Fonts_Test.git
   ```

2. 以任一現代瀏覽器直接開啟 `index.html`，無須建置工具或本機伺服器即可使用。

> **為什麼有些地區看起來一模一樣？**
> 因為本頁不載入任何外部字型，當兩個地區顯示出完全相同的字形時，表示目前的作業系統或瀏覽器尚未安裝該地區的獨立字型，系統便會將兩者回退（Fallback）至同一套本機預設字型。這個現象也能幫你快速檢驗裝置對多語系 CJK 字型的支援程度。
